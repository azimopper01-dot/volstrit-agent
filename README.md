# Volstrit Agent

Telegram kanal uchun SMM AI agent. Fond bozori mavzusida avtomatik post tayyorlaydi, admin tasdiqlagach kanalga chiqaradi.

## Xususiyatlar
- Kunlik postlar (08:30, 13:00, 18:30)
- Admin tasdiqlash tizimi
- Haftalik so'rovnomalar
- AI orqali kontent generatsiyasi (Gemini)

## Texnologiyalar
- Python 3.11
- aiogram 3.x
- Google Gemini API
- SQLite
- APScheduler
